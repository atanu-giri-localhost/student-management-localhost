## 3. Stakeholder Gate Rules for Implementation Teams

1. **Before Starting Phase 1–2 Implementation:** Obtain sign-off on **OD-01**, **OD-02**, **OD-03**, **OD-06**, **OD-13**, and **OD-14** (Phase 0 Sign-Off Gate).
2. **Before Starting Phase 3–4 (Students, Parents, Teachers):** Obtain sign-off on **OD-04**, **OD-05**, **OD-07**, **OD-12**, and **OD-15**.
3. **Before Starting Phase 5–7 (Attendance, Exams, Timetable):** Obtain sign-off on **OD-08**, **OD-09**, **SUB-TT-01**, and **SUB-EX-01**.
4. **Before Starting Phase 8 (Finance Ledger):** Conduct the mandatory Finance Design Review and obtain explicit written sign-off on **OD-10** and **OD-11** (plus **OD-01** reversal authority and **OD-12** teacher historical fee scope).
5. **Follow-Up Migrations Rule:** If an approved stakeholder decision requires additional tables or columns (for example, `payment_reversals`, `credit_notes`, or `holiday_calendar`), author a new numbered SQL migration (`migrations/0002_*.sql`) via `npx wrangler d1 migrations create sms-coaching-d1 <name>` — never edit committed `migrations/0001_initial_schema.sql`.
